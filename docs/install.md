# 安装与版本固定

## 包管理器

```bash
npm install @acme/ui        # 最新发布版
npm install @acme/ui@1.0.0  # 精确旧版
```

## 文档与组件版本一致

每个版本的文档都从该版本发布时的 **git commit 与 tree hash** 构建：

- 后续向分支推送代码不会改变任何已发布版本的属性表或示例；
- 旧版文档只会加载该版本 worktree 中提取并通过验证的组件；
- 若尝试用不同 commit 覆盖同一版本号，入库流程会直接拒绝。

页面底部展示了该版本对应的 commit 短哈希，可据此核对。

## 浏览器支持

现代浏览器（原生 ESM、CSS 自定义属性）。交互示例本身在隔离预览源中运行，
主站不会向第三方源发送登录凭证。
